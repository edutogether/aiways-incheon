Curriculum-based Learning Design

교육과정 기반 수업 설계

본 프로젝트는 실과의 생활 자원 관리, 사회의 지속 가능한 미래와 지역사회 문제 탐구, 국어의 토의·조정 역량을 연결하여 학생이 생활 속 배출 문제를 발견하고 AI와 데이터를 활용해 학교 자원순환 UX를 개선하도록 설계한 6차시 융합 수업입니다.

실과

생활 자원 관리

생활 자원 관리, 합리적 소비, 재활용·재사용 실천을 실제 문제와 연결합니다.

사회

지역사회 문제 탐구

인천 수도권매립지와 자원순환 문제를 생활권 기반 지역사회 문제로 탐구합니다.

국어

토의와 판단 조정

AI 제안과 자료를 근거로 비교하고, 딜레마 토론과 설득적 표현으로 판단을 조정합니다.

창체

실천과 확산

3초 판단 도우미, 판단 보류함, 대시보드 점검을 교실 밖 실천과 확산으로 이어갑니다.

연계 성취기준

2022 개정 교육과정 기반 · 자원순환 UX 프로젝트 적용

6실02-03

생활 자원의 올바른 사용과 환경을 고려한 재활용·재사용 실천

6실05-03

실생활 문제 해결 프로그램을 협력하여 작성하고 산출물 공유

6실05-04

디지털·아날로그 데이터의 특징과 AI 활용 데이터 유형 탐색

6실05-05

인공지능이 만들어지는 과정을 체험하고 사회적 영향 탐색

6사12-02

지속 가능한 미래를 위한 지구촌 문제와 해결 방안 탐색

6국01-02

주장과 근거의 타당성을 평가하며 듣고 토의·토론하기
