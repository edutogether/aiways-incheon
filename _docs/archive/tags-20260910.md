## 2단계에서 할 것 (확인 후)

```
git update-ref refs/archive/tags/<이름> <커밋>
git tag -d <이름>
git push origin :refs/tags/<이름>
git push origin refs/archive/tags/<이름>
```

⚠️ `.githooks/pre-push`가 freeze 태그 삭제를 막는다. **훅은 지우지도 고치지도
않는다** — 이 작업에 한해 `--no-verify`를 쓰고, **썼다는 사실을 보고에 밝힌다.**
훅은 그대로 남아 앞으로도 실수로 지우는 것을 계속 막는다.
