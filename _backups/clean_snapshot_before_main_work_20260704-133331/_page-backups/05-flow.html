6-Lesson Journey + Experience + Sharing

차시흐름

문제 발견에서 AI 활용, 인간 검증, 블록코딩·티처블머신·바이브코딩을 거쳐 대시보드 체험과 배포·공유까지 이어지는 수업 여정입니다.

1차시 · 문제 발견

환경을 강요하지 않는 문제 발견

학생 VOC와 교실 관찰로 버리는 순간의 혼선을 찾습니다.

2차시 · AI

생성형 AI로 아이디어 확장

AI와 함께 학교 쓰레기 문제를 해결할 UX 후보를 탐색합니다.

3차시 · Human 2

딜레마 토론과 인간 검증

AI 제안을 그대로 믿지 않고 기준으로 다시 판단합니다.

4차시 · Coding

블록코딩과 이미지 분류

이미지 분류 개념과 AI가 헷갈리는 이유를 체험합니다.

5차시 · Teachable Machine

우리반 AI 모델 학습

우리반 물건 사진으로 분리배출 모델을 학습시킵니다.

6차시 · Vibe Coding

앱 기능을 말로 설계하고 개선

자연어로 앱 기능을 설계하고 UX 프로토타입을 개선합니다.

체험 · Dashboard

대시보드 체험과 실전 배포

교사 제작 대시보드로 데이터가 쌓이는 방식을 봅니다.

확산 · Output

산출물 공유

홈페이지, QR, PLAY BOOK으로 결과를 다른 반과 공유합니다.
